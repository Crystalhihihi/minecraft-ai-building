# 房屋细节部件总目录(供手搓参考样板用 — 2026-08-07)

> 用途:你按此目录手搓样板件,我蒸馏成生成器/卡。每件:是什么/在哪/典型尺寸/材料惯例/变体/反例(别做成什么样)。
> 总原则(来自调研与实测):**装饰集中于结构缝(转角/基座/檐口/洞口),允许留白;纵深(凹凸)优先于贴花。**

## 一、房顶(roof)

| 部件 | 说明 |
|---|---|
| 屋脊(ridge) | 两坡交线。做法:脊条(整砖/原木梁)通长压顶,两端可翘头(兽首/卷草=楼梯/头骨)。反例:两坡直接对接不留脊(一条黑缝) |
| 檐口(eaves) | 出挑 1-2 格是灵魂。**有挑檐必有椽**:檐下每 1-2 格一根椽头(倒放楼梯薄端朝外)+檐口第一排瓦用对比色半砖收边。反例:屋顶与墙齐平(盒子戴帽) |
| 山墙收边(barge/verge) | 人字顶两端三角的斜边:楼梯/整砖沿斜线压边(博风板),底端可翘。反例:山墙三角裸着不收 |
| 谷沟(valley) | 两坡相交的内凹斜沟:45° 对角线,半砖/倒放梯成沟,止于脊下不翻越。反例:两坡硬撞出黑缝 |
| 老虎窗(dormer) | 稀!:坡面 1 面坡最多 1-2 个,自带小人字顶+墙+窗,底与坡面齐。**老虎窗成群=翻车**(实测) |
| 烟囱(chimney) | 石砖/砖柱(1x1/1x2),穿屋顶处泛水圈(凸 1 格或楼梯圈),顶口压一圈+篝火冒烟。别贴正立面中轴 |
| 屋面肌理 | 主色瓦为主,每 N 排换一条深色排(呼吸感);旧感=局部掺 5-10% 苔/裂瓦 |
| 起翘/曲线(可选) | 中式/日式:檐口两端上翘 1 格(翼角),坡面微凹曲线。直坡房别硬加 |

## 二、墙面(wall)

| 部件 | 说明 |
|---|---|
| 基座放脚(plinth) | 墙根凸 1 格高 1-2,材质深/糙一号(石基),墙身退后半格升起。**没它墙像纸插地上**(仅吊脚楼豁免) |
| 转角柱(corner post) | 两面交角通高竖条(骨材对比色),可 3-4 格一节凸半格。木骨=深原木,石构=浅石 |
| 层间线脚(string course) | 楼层间通长细横线(凸半格半砖),把立面切三段。两层以上才要,一层做了碎 |
| 檐口线(cornice) | 墙顶收口:椽头/封边/牛腿,让屋顶"坐"在墙上 |
| 壁柱(pilaster) | 墙面上的半凸扁柱,间距 3-5,划分墙面节奏。大面墙才有,小屋一面墙一根都多 |
| 墙身肌理 | 主材 70-90% + 辅材 10-30% 随机掺(石墙掺苔石/裂砖,木墙换色板条);**竖向木板条可按排换色** |
| 窗间墙节奏 | 窗距匀(3-5 格),上下层窗对位;大窗下必有窗台,小窗可裸 |
| 旧化(weathering) | 底部 1-2 格掺苔/裂,檐下一线稍深(雨痕),转角比面中略深 |

## 三、门窗(openings)

| 部件 | 说明 |
|---|---|
| 门口(entrance) | 系统件(最高优先):凹龛(门退 1-2 格)+门框(深框浅墙)+门楣+门扇+台阶(stoop 1-3 级)+雨棚(挑 1 格)+两侧灯。**裸门贴平墙=失败** |
| 主窗 | 玻璃内凹 1 格(第一细节)+窗台半砖出挑+(选做)窗楣/拱心石。**正立面全做,侧面隔窗,背面可裸;绝不每窗都套**(实测翻车) |
| 小窗/透气窗 | 阁楼/山墙尖 1x1 或 1x2 竖缝,可裸(只内凹) |
| 百叶/花箱(手搓区) | 活板门已禁;替代:百叶=羊毛/木板嵌墙两侧,花箱=半砖槽+花 |
| 拱窗(哥特/教堂) | 尖拱/圆拱,拱心石居中,竖梃分格 |

## 四、支撑与结构件(support)

| 部件 | 说明 |
|---|---|
| 牛腿/托臂(corbel/bracket) | 挑出件(阳台/挑檐/上层悬挑)下方的倒三角托:倒放楼梯 1-2 格,间距 2-3。**悬挑无托=漂浮**(实测) |
| 立柱(post) | 门廊/阳台/骑楼下的细柱(原木/石),落点必有础(半砖/石墩) |
| 斜撑(knee brace) | 柱与梁交接的 45° 短撑(楼梯斜放),木构建筑的标志件 |
| 扶壁(buttress) | 石构高墙外侧的墩,下宽上收 2-3 节,间距 3-5,抵住墙脚。哥特还有飞扶壁(拱桥式) |
| 悬挑(jetty) | 上层整体挑出 1 格(中世纪民居),挑出端下沿一圈倒放梯托架+梁线脚 |
| 桁架(truss,山墙内/大跨) | 山墙三角内可见的木三角架:中柱+斜弦+拉杆 |

## 五、内部(interior)

| 部件 | 说明 |
|---|---|
| 楼板(floor) | 层高分 3-4 格;板下可见梁(间距 2-3,原木) |
| 楼梯(staircase) | 贴墙/转角带平台,扶手(栏杆)靠外,梯下可做储物。**手摆朝向=翻车高发,走 staircase.py** |
| 家具组团 | 按房间功能成组摆放(不是一字排!):工作间=台+炉+砧 L 形围一角+墙面工具;储物=箱墙+桶+架;厨房=壁炉(内凹+烟囱)+案板+锅;卧室=床+柜+灯。**箱上必须有半砖/空气不然打不开** |
| 照明 | 每个封闭空间有点光(灯笼/火把),色温统一;楼梯转角/床头晕重点 |
| 隔断 | 大间用柱/半墙/书架隔而不堵,保持 2 格走道 |

## 六、场地(site)

| 部件 | 说明 |
|---|---|
| 入户路(path) | dirt_path/碎石板,门口到主路,微弯,边缘渐稀(别切直线硬边) |
| 围栏(fence/wall) | 院界矮栏(栅栏/石墙),门口开口,角柱加粗 |
| 院灯 | 杆 3 格+灯笼,沿路和门口,间距 5-8,别均布成路灯阵 |
| 点缀 | 干草堆/柴堆/水桶/农具靠墙根,花坛压边(半砖围),一两处就够 |
| 地形收边 | 房子与地面交接:坡地挡土墙(石),平地小台阶,**不许墙角悬空或埋半墙** |

## 七、总反例清单(手搓时避雷)

1. 装饰每面墙全做满(堆砌)——次立面要留白
2. 屋顶与墙齐平无挑檐、无椽子
3. 山墙三角镂空/裸门贴墙/悬挑无托/树干式方柱
4. 家具一字排开堵门堵路、箱上压死打不开
5. 活板门(已全线禁用)、楼梯朝向混放(徒手)
6. 窗边全做窗套、老虎窗成群、路灯均布成阵
