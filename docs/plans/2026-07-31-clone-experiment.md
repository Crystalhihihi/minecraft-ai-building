# 克隆实验(E6):照图施工 + 量化 diff 迭代环(2026-07-31)

> 触发:用户判定"aibuilding 到极限了,只有大概样子"。成本顾虑同日解除(会员额度可接受,见 HANDOFF 指令 3 修正)。
> 本实验是给"极限论"定性的决定性实验,同时产出 diff 批评家管线——以后一切质量迭代的发动机。

## 目的与判定

- **主问题**:在迭代不限量(额度内)的前提下,系统对照真人参考图能逼近到什么程度?
- **两种结果都有价值**:
  - 相似度曲线持续爬升 → "极限"不成立,是工作流缺反馈环;管线转为常设
  - 曲线早早躺平(连续 3 轮 Δscore < 0.02)→ 卡点被 diff 数据精确定位,转型(检索装配/人机分工)有实据
- **对照组**:同题同模型,走现有"渲染自检"环(无量化 diff),相同轮次预算。两组终分对比证明环的价值

## 目标选择(已看完全部 10 张参考图)

- **首选:`优秀建筑图片/114017853925562..png`(深色云杉木屋)**
  理由:近正立面单一视角、vanilla 画面无光影包、无地形干扰、材质单一(云杉/原木系)、复杂度中等偏低——首次跑通管线的干扰变量最少
- **第二目标:`333417853916652..png`(水上吊脚木屋)**:加桩基/水面元素,管线跑通后升级用
- **排除**:3563/9011(建筑群)、Screenshot(巨型结构)、0178(重光影黄昏)、2839(藤蔓繁茂,留作后期挑战)
- 参考图是视频截图,带水印/台标 → diff 前预处理裁边

## 管线(7 步)

1. **视觉拆解**(K3 多模态):参考图 → 结构 spec。模板固定:体量分解(各体块 xyz 尺寸与相对位置)/比例锚点(以某已知块定标)/材质板(MC block 清单,走 search_blocks 校验存在)/特征清单(屋顶形式、窗洞、装饰层)/不可见面显式标注"自由发挥"
2. **生成器编码**:spec → Python 生成器脚本。**铁律:一切几何走代码,禁止逐块手写坐标**(精灵树定论"模式即算法"的一般化;E2 已验证 K3 有此本能)。参数集中文件头部,便于迭代只改参数
3. **建造**:dev server 放置(propose → SiteGate → set_blocks)
4. **同机位渲染**:`render_region` gl 模式,固定 azimuth/elevation/距离/persp,导出 PNG 落盘
5. **diff 计算**(本地脚本,不调模型,零 token):
   - v1:建筑轮廓 mask IoU(同机位二值剪影)+ 材质色板直方图 χ² 距离
   - v2:3×3 分区轮廓 IoU(定位最差差异区)+ 高度图 MSE(topdown+结构扫描合成)
   - 不做整图 SSIM(天空/植被噪声大);先 mask 后算
6. **迭代**:diff 输出(总分 + top-3 最差分区方位 + 色板缺失/多余 top-3 + 与上轮 Δ)喂回 agent → 改生成器 → 重建 → 再 diff
7. **终止**:预算上限 15 轮;躺平判定(3 轮 Δ<0.02)提前停;成功判定 = 轮廓 IoU ≥ 0.85 且用户人工盲评"神似"

## 阶段拆分

- **阶段 0**(本地,1 步):diff.py 骨架 + 机位标定自验 → 产出:两张已知建筑的渲染对齐分数
- **阶段 1**(首跑):视觉拆解 → v1 生成器 → 首建 → 首轮 diff 基线分 → 对照组同步开跑
- **阶段 2**(迭代):跑满预算或躺平,全程记录
- **阶段 3**(结案):数据表(轮次/score/token/墙钟/Δ 曲线)写入 `docs/experiments.md` 作 E6;产物存 `scratch/phase8/clone/`;结论二选一(管线常设 or 转型实据)

## 风险

- 机位对齐误差 → 阶段 0 先行,不过不开跑
- 单视角背面不可知 → spec 显式标注,diff 只算可见面,不罚背面
- 参考图水印/字幕 → 预处理裁边
- 色板映射主观 → 映射表人工(用户)过一眼再锁
- 对照组公平性:同模型、同轮次上限、同题;对照组不许看 diff 数值
