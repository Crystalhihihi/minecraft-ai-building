# 大树生成全线修复计划(2026-08-08 grill-me 定稿)

> 决策方式:grill-me 访谈,逐项与用户钉死。本文档是唯一权威记录,HANDOFF 快照从简引用。

## 范围

六项 + 全部旧债,一次清账:
1. 叶图元密度场重写(治"树叶全是一个个球")
2. 分叉戟(新干形)
3. 多柱林 = 榕树式气生根成柱(与悬空根项合并)
4. 悬空根 = 露根拱起基座门洞式
5. 倒悬瀑 = 根瀑(排最后)
6. 矮胖墩 = 新干形 stubby
7. 旧债:针叶塔形逐层环裙边、垂柳真垂坠枝、板根方向与干形解耦、主枝 2→1 宽半砖过渡

## 验收标准

- 关键节点实机截图验收:密度场首版、每个新拓扑的第一棵树(stubby/fork/banyan/根瀑)
- 其余:离线三视角(az 0/45/90)渲染 + validators/support_check + 裸木检测数据
- 教训来源:tree_png.py 单视角多次误导;v3 后纯离线验证实机翻车

## 形态定义(访谈钉死)

### 叶图元:metaball 密度场
- 每个簇心贡献势场,叠加后以低频相干噪声(确定性 value noise,seeded)扰动阈值取等值面
- **壳体 + 内部空**:只填等值面带(壳厚 2-3 格),冠内留空可藏灯/穿行
- 六叶形的簇位摆放逻辑(layers/umbrella/mist/blob 各自规则)保留不动,只换"成面"这一步
- 地标树性能:每簇势场截断(影响半径外不求值),块数预算沿旧例(40 高 ~2 万 / 70 高 ~5 万,壳体应显著低于此)

### 分叉戟 fork(agent 判断,用户授权)
- leader 在 0.25-0.45h 分裂 2-3 叉,近平行上冲(锐、直)
- 共享一个整冠;叉身贯入冠底保持"戟"可读
- 与 spirit_candelabra(螺旋干+平展枝烛台)生态位错开

### 多柱林 = 榕树气生根成柱
- 枝干垂下气生根 → 触地 → 增粗成柱,多柱共享一冠
- 取代 banyan_court 近似卡

### 悬空根 = 露根拱起门洞式
- 现有 crawl roots 加强:拱高到可穿行成门洞,服务幻想地标
- 红树高跷支柱根明确不做(mangrove_swamp 维持近似卡)

### 倒悬瀑 = 根瀑
- 根幕沿真实崖壁垂落;最终方向=读地形数据(SiteAnalyzer 路线),生成器不再纯离线
- **排在全部工作最后**,先把正常树做好

### 矮胖墩 = 新干形 stubby
- 新拓扑:超短 leader + 近地分枝 + 冠压极低
- 引擎改动:比例护栏放行矮胖组合,超粗干(>12?)收分/削角适配

## 施工顺序(agent 排,用户授权)

1. **阶段1**:密度场 kernel + 阔叶四冠形迁移 → 实机验收
2. **阶段2**:conifer_spire/palm_umbrella/weeping_tree/garden_tree 迁移 + 针叶裙边、垂柳债
3. **阶段3**:stubby + fork → 实机验收
4. **阶段4**:门洞露根 + banyan 气生根 → 实机验收
5. **阶段5**:板根方向解耦、主枝 2→1 宽半砖过渡
6. **阶段6**:根瀑(地形耦合)

## 设计根因记录(为什么树叶全是球)

设计词表有 8 干形 + 6 叶形,但几何词汇表只有"单 leader 偏移曲线"和"镂空椭球簇"两个词。
已实现的都是同一拓扑内的参数变体;未实现的都是需要新拓扑的。叶侧 6 形摆放逻辑不同但图元相同 → 面貌趋同成球。本轮修复=把几何词汇表补齐到设计词表的水平。
