# 参考知识库·道路/路径/广场 — 2026-07-30

> 来源:explore 子代理(medium 档)。社区教程 + 原版村庄生成机制 + GDMC 经验。数字为社区共识区间/建议值,非唯一标准。

## 1. 核心技法

### 1.1 道路宽度与建筑尺度
- 分级宽度:乡道小径 **2–3**;村巷/住宅街 **5–7**;主街/大道 **9–13**(都会教程中城际公路到 30)。相邻等级宽度差 ≈2 倍,层级一眼可读。
- 街道围合比(借自现实城市设计):街宽 : 沿街立面高 ≈ **1:1(强围合)–2:1(舒适)**;>3:1 失围合、像停车场。小屋立面 6–8 高 → 街宽 5–7 正好。
- 原版村庄路实测宽 1–3(土径),与"村"的尺度自洽;城市化不是把村路加宽,而是分级。
- 路随建筑走,不要建筑随路走(metropolis 教程:roads created as needed, not used to force buildings)。

### 1.2 剖面:路拱/边沟/路缘
- 路拱:中线抬高 **0.5(顶半砖)~1(整砖)**,宽 3–7 时向两侧对称跌落 — road_segment.py 已实现。
- 边沟:路肩外 **1 宽 × 1 深**,留 ~15% 自然缺口 — 已实现。
- 基层:面层下垫一层(原版 1.8 起砾石路下垫圆石防塌入洞穴) — fill_material 已实现。
- 城市路缘:人行道比车行道高 **0.5 或 1**,宽 **1–2**;现代风标线 = 白色混凝土/羊毛,虚线节奏 1 实 3 空。

### 1.3 铺装材料渐变
- 同一路面 **≥3 种近色材料**噪声混合,忌单一(官方 Zaypixel 教程第一原则:vary + weathered)。
- 中世纪:砾石+圆石+安山岩(+苔石),掺 **10–20%** 楼梯/半砖做"开裂磨损"(论坛共识)。
- 按等级递进:泥土/砂土/灰化土(乡道)→ 砾石+圆石+安山岩(村街)→ 石砖+磨制安山岩(城街)→ 砖/平滑石+标线(大道)。
- 中心↔边缘差异化:中心磨损重(土径)、边缘硬质(石) — 已实现;车辙感 = 两条平行土径线夹中间砾石。
- 群系配色:沙漠=平滑砂岩(原版沙漠村即如此),针叶林=灰化土+苔石+浆果丛。

### 1.4 弯道与走向
- 忌长直路到底;小巷每 **3–5 格**把中线横移 1 格得"有机抖动"(论坛原话:make it curve)。
- 禁长段 45° 对角线(锯齿刺眼);转弯用像素圆表(Plotz / Donat)铺阶梯弧。
- 转弯内半径 **≥ 2×路宽**,否则内侧台阶退化挤死。
- 地形适应:原版村庄路的著名缺陷是不顾坡度直上悬崖;GDMC 做法 = 坡度惩罚 A*(cost = 距离 + w·|Δh|²)+ 沿路整平(见 pcg 调研 §3)。

### 1.5 路缘/植被/照明节奏
- 灯:间距 **8–12**,村巷两侧交错、大道对称;柱高 **3–4**(栅栏/去皮原木)+灯笼。依据:1.18 前防刷怪需光照 ≥8(火把光 14 每格衰减 1 → 间距 ≤12);1.18+ 光照 >0 即防刷,间距转为纯美学节奏。
- 行道树/绿篱:每 **6–10** 格一处,允许树叶溢到路面边缘软化边界。
- 节奏在路口、建筑门口打断重起,不机械通铺。

### 1.6 广场:形状与聚焦点
- 围合比(Sitte 原则):广场直径 **≥ 主建筑檐高 ×1,≤ ×2–3**;村镇主建筑 10–14 高 → 广场 12–30 跨。>4:1 即"大而空"。
- 形状:正式=几何形(方/圆/八角),有机=变形虫;村庄=几何形小广场(原版水井/钟集会点即几何中心语义)。
- 聚焦点**唯一**且居中(或黄金分割偏置):喷泉(15–25 广场配 **5×5 或 7×7** 水池)、雕塑(**1–2** 高基座,quadruped_statue 已有)、孤植树+环形座凳、井/钟(原版集会点)。
- 聚焦物高度 ≤ 沿街立面高的 1/2,不抢建筑。

### 1.7 铺装图案尺度
- 图案模数 **3×3 或 4×4** 重复;人行尺度下单元 >4 会读出"网格感"。
- 圆形广场用同心环,环带宽 **3–4**,环心即聚焦点。
- 外圈 **1–2** 宽对比色收边带(读作"地毯边"),与相接道路材料在收边处咬合过渡。
- 微高差定义空间:整体下沉/抬升 **0.5**(半砖)即够,保持无障碍。

## 3. 反例

1. **直线到底无节奏**:笔直通向地平线,无弯、无灯、无边饰。药方:每 3–5 格中线抖 1 格 + 每 8–12 格一盏灯。
2. **铺装单一**:整条路/整个广场一种块,机器感。药方:≥3 近色块噪声混合 + 10–20% 破损件(楼梯/半砖/苔石)。
3. **广场大而空**:无聚焦点、无围合、D:H > 4:1 → 停车场。药方:唯一中心物(喷泉/树/雕塑)+ 直径 ≤ 沿街建筑高 ×3。
4. (原版自带反例)**障碍物占动线**:原版村庄会把灯柱/树生成在路中央。聚焦物和家具永远放广场中心或路缘,别放动线上。

## 4. 对模式库的建议

已有 `road_segment.py`(直线 x/z、平地、路拱/边沟/材料渐变/坐标哈希)。缺:

1. **road_curve.py** — 阶梯弧段:内半径 ≥2×路宽,角度 45/90,剖面与材料参数直接复用 road_segment;像素圆表内置(免查 Plotz)。
2. **road_junction.py** — T/X 路口补片:转角圆角、两路材料在补片内过渡混合、路口内自动取消边沟与路拱。
3. **地形跟随** — 现段只吃平 y;应按 terrain summary 逐列取 y,Δy=1 用楼梯/半砖过渡,纵坡 ≤ ~1:3;远期接 BACKLOG B2 的坡度惩罚 A* 寻路。
4. **plaza.py** — 参数:形状(rect/circle/ellipse)、半径/半边长、图案模数(格纹 3–4 / 同心环带宽 3–4 / 碎拼)、收边带 1–2、中心 focal 钩子(挂喷泉/雕塑/孤树子模式)、边缘高斯渐变进地形。
5. **fountain.py / plaza_tree.py** — 聚焦点专用:水池 5×5/7×7+中心柱;孤树+环形座凳。雕塑复用 quadruped_statue + 1–2 高基座即可,不必新写。
6. **街道家具节奏写进规则而非模式** — lamppost.py(高 3–4+灯笼)可立项;"每 8–12 交错布灯、每 6–10 一处绿化、路口打断重起"适合进 AGENTS.md 规则层。
7. **城市 profile** — 人行道(+0.5/1,宽 1–2)+标线,与现有 medieval 默认并存为材料预设包,road_segment 只需加 preset 参数。
