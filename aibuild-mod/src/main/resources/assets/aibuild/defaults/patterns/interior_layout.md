# interior_layout.md — 房间划分与室内布局规则(先分房,再陈设)

> 配套:模式卡 `interior_rooms`(成套陈设生成器)与 `furniture`(单件家具图鉴)。
> 本文回答两个问题:**给定建筑内空怎么切房间**,以及**房间里东西怎么摆才进得去人**。
> 尺度基于社区通行约定:1 格 = 1 m,玩家宽 1 格、高 2 格;房间尺寸参考
> Minecraft Architectural Standards(MCS,以格为单位)与主流内饰教程。

## 0. 术语与坐标约定

- **内空** = 墙体内侧围出的矩形,记 净宽 W × 净深 D × 净高 H,**不含墙厚**。
  外墙 9×11 的房子,1 格墙厚下内空只有 7×9。
- **家具站立层**:地板方块上面那一层(y = floor_y + 1),即 `interior_rooms` 的 origin.y。
- **通道** = 没有任何方块(y+0 与 y+1 两格皆空)的连续格列;人占 1×2。

## 1. 层高(H)

| 用途 | H |
| --- | --- |
| 阁楼/地窖 | 2(最低,压抑,别当正常房间) |
| 小屋/紧凑居室内空 | **3(下限)** |
| 舒适居室 | **4(推荐默认)** |
| 挑高客厅/大堂 | 5-6 |

- H=3 时吊灯会撞头:灯挂 y+2,人高到 y+1,刚好;但别再吊第二格 chain。
- 最高家具 4 格(dresser height=3+顶板、bookshelf height=4),H≥4 不顶头。

## 2. 分房间:给定 W×D 内空怎么切

**顺序:先动线,后房间。**

1. **先划交通核**:楼梯间 + 走廊。楼梯贴墙或塞角(详见 §5),走廊贴着楼梯/入口走。
   剩下的完整矩形才是可分的居室面积。
2. **大房占采光面**:客厅/卧室/书房必须分到外墙面(开窗),放在采光好的一侧;
   厨房、储藏、卫生间这类可以内凹,给高窗就行。
3. **按最小开间校验**:每个房间切完后对照 §3 的表,任一边不达标就合并或重切——
   宁可少一间房,不要一间进不去人的房。
4. **门洞定位**:门开在墙中部或偏 1 格;门内侧 1 格是禁放区(§6)。
5. **逐房陈设**:每个房间调一次 `interior_rooms`,传真实内空与门洞位置。

典型 7×9 单层内空切法(供参考,非唯一解):南侧留 2 宽走道(7×2),北侧切成
4×4 卧室 + 3×? 厨房;或 5×5 客厅 + 2 宽走廊 + 4×4 卧室。

## 3. 最小开间表(净尺寸,任意旋转)

| 房间 | 最小 W×D | 舒适 W×D | 依据 |
| --- | --- | --- | --- |
| bedroom 卧室 | 4×4 | 5×6 | 床 1×2 + 床头柜 + 2 宽柜 + 三面通道 |
| kitchen 厨房 | 4×4 | 5×5 | 厨台长 3 贴墙 + 2 宽橱柜 + 台前通道 |
| living 客厅 | 5×5 | 6×7 | 沙发 3-4 + 壁炉 3 宽对墙 + 书架 + 中环通道 |
| dining 餐厅 | 4×5 | 5×6 | 桌 1 排 + 两侧椅子各 1 排 + 绕行通道 |
| study 书房 | 4×4 | 4×5 | 书桌 3 + 书架 2 宽 + 灯 |
| corridor 走廊 | 1×3(裸廊) | 2×N | 见 §4 |
| 卫生间/储藏 | 2×3 | 3×3 | 炼药锅+桶即可,本卡不覆盖 |

舒适档参考 MCS 的换算(small bedroom 9×8 Bl 是按真实家具比例算的,
MC 拼装家具比真实家具小,上表已按本项目家具图鉴的实际占地压缩)。

## 4. 走廊

- **1 格宽 = 法律下限**(人能过),**2 格宽 = 舒适**(社区共识:现实 36" 走廊≈1 格,
  但 MC 里 2 格才不憋屈)。
- 净宽 1 的走廊**什么都不放**:一格灯柱就把路掐断。照明用墙挂 wall_torch / 顶挂 lantern。
- 净宽 ≥2 才允许点缀,且点缀必须**单侧、错位**(灯在左 1/3 处,盆栽在右 2/3 处),
  同格左右对放会把 2 宽掐成 0。`interior_rooms` 的 corridor 模板已按此布。
- 长走廊每 4-5 格一处光源,不然刷怪。

## 5. 楼梯间位置

- **贴墙、塞角、顺梁**:直跑梯贴一侧墙,转角梯(L/U 形)塞墙角;不要把楼梯
  竖在房间正中,它会同时吃掉两层的可用面积。
- 梯段净宽 ≥1(2 舒适);头顶净高 ≥2(人走斜坡不撞头,即沿梯向上每格上方留 2)。
- **楼梯口不对床、不压床**(见 §7 pitfalls):上层楼梯段的下方斜空间在底层是
  低矮区,放床/书桌必撞头,那里只配放储物桶。
- 上下层楼梯洞口长边顺梯方向,洞口周围 1 格别放家具(坠落+堵路)。
- 朝向规则一律查 `stair_orientations.md`(facing=高侧),别手推。

## 6. 门、窗与对位

- **门**:宽 1 高 2(原版门即此尺度);门内侧 1 格是**禁放区**——既挡开门又挡人。
  `interior_rooms` 的 doors 参数声明后由生成器强制清空。
- **门不对床**:床不要摆在开门直视、门扇直冲的位置;床贴的门对侧墙或侧墙最稳
  (生成器主墙选择自动避开门墙)。
- **窗**:
  - 每间居室至少 1 窗;采光面有限时优先级 卧室/书房/客厅 > 餐厅 > 厨房 > 走廊/卫生间。
  - 标准窗 2 宽×2 高或 1×2 竖窗,窗台在 y+1(家具站立层 +1,即人站立视线高度);
    厨房/卫生间可用 y+2 的 1×1 高窗。
  - 窗与门对位(相对或相邻墙错半格)形成穿堂视线,小房子显大;但窗别正对床头正上方。
- **家具贴窗**:矮件(床、沙发、厨台)可靠窗墙;高件(书架、衣柜、 dresser height≥3)
  别挡窗,会把采光全吃掉。

## 7. 家具尺度与间隙表

占地以 `furniture` 图鉴为准(单位:格,宽×深,不含高度):

| 家具 | 占地 | 备注 |
| --- | --- | --- |
| bed 床 | 1×2 | 真床方块;床头贴墙,两侧+床尾至少一侧留 1 通道 |
| table 桌 | 1-4×1 | 餐桌居中,四周一圈通道 |
| chair 椅 | 3×1(含扶手 sign) | 入座走椅背后;两把之间留 1 |
| sofa 沙发 | 2-6×1(另+两端扶手各 1) | 贴墙;面前留 1-2 |
| bookshelf / cabinet | 1-4 宽×1 | 高件,别挡窗 |
| kitchen_counter | 2-6×1 | 台前留 1 操作位 |
| desk 书桌 | 2-4×1 | 桌前留 1 坐位 |
| dresser 抽屉柜 | 1-3×1,高 2-4 | 高件 |
| fireplace 壁炉 | 3×1 | 正前方 1 格烤火位必空 |
| piano 钢琴 | 3×1 | 客厅可选大件 |
| lamp_post / flower_pot | 1×1 | 塞角,别塞路 |

**间隙铁律:**
- 人能通过的最小间隙 = **1 格宽 × 2 格高净空**;主通道(门到门、门到床/台)建议 2。
- 从每个门洞出发,必须能走到**每件家具的正前方**(床=床尾+脚侧,椅=椅背,
  台/桌/柜=正面 1 格)。`interior_rooms` 用 BFS 强制此条;手摆散件时自查。
- 半砖/地毯不挡路(低于半格),但压力板桌面、栅栏腿都挡——别把"看着矮"当"能穿过"。

## 8. pitfalls(血泪清单)

- **家具堵门**:门内侧 1 格放了桌/柜/灯,门能开人进不来。声明 doors,让生成器清场。
- **房间无窗**:黑房+刷怪+压抑三连。分房阶段(§2.2)就锁定采光面,不是事后补。
- **通道 <1**:两件家具斜对放、灯柱放路中、椅子离墙 0.5 格——视觉上"好像有缝",
  判定上就是过不去。一切以完整空格为准。
- **床头顶楼梯**:上层楼梯斜段压在下层床头上方,睡觉撞头;楼梯下斜空间只放储物。
- **床三边封死**:床嵌进墙角两边贴墙、床尾再顶柜,上不了床。床至少脚侧+床尾可达。
- **羊毛/混凝土冒充床**:必须用真床方块(color_bed, part=foot/head)——项目耻辱柱,严禁。
- **高件挡窗**:3 高书架/衣柜放窗前,采光归零。高件放无窗墙。
- **柜子用 chest 拼**:chest 两两合并成大箱子破坏网格;柜/抽屉一律 barrel(furniture 卡已处理)。
- **楼梯洞口下放家具**:上层开口正下方 1 格留空,防坠落也防"天花板长桌子"。
- **内饰先于墙体**:家具卡假设墙/地/顶已就位;先陈设后砌墙必然嵌块。顺序:壳 → 分房 → 窗门洞 → 陈设 → collision_check。
- **走廊对摆**:2 宽走廊左右同格各放一件 = 断路。单侧错位。

## 9. 图鉴之外的常用件(文字做法,暂无生成器)

原版没有家具方块,以下社区经典拼法可手动补(放完务必复跑 collision/support_check):

- **吊灯**:chain 1-2 格 + lantern 挂在天花板下;H=3 时只挂 lantern 不加 chain(撞头)。
- **地毯**:carpet 满铺或床边/沙发前一块;不挡路,可直接盖在地板上。
- **挂墙画/物品框**:painting、item_frame 是**实体**,set_blocks 放不了,慎用;
  需要时用 map-less 替代:墙上挂 banner 或 item_frame 留待玩家自己放。
- **窗帘**:窗两侧竖挂 banner 或竖排羊毛,高出窗一格。
- **盥洗台**:cauldron + 上方墙挂 tripwire_hook(当水龙头)或 lever。
- **餐桌布/桌旗**:长桌 pressure_plate 面上不能再叠 carpet(会浮),桌布效果用
  桌体木种与地毯拼色表达。
- **沙发靠枕**:沙发楼梯背后一格放 colored wool/concrete 一排,比扶手高一格。
